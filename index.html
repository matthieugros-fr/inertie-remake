Règle

Le vaisseau ne doit rien toucher. On se pose, le cosmonaute va chercher disquettes et savants (attention à l'oxygène). L'énergie se recharge en survolant les « E ».
Menu : 1 jouer, puis le code de la planète (J12C58 pour la première).

À propos

Inertie, Ubi Soft 1987 : programmation Christophe Le Bouil, graphismes Patrick Daher, musique Xavier Talgorn.

Mode « Original » : le code Z80 du jeu tourne dans une machine CPC simulée, avec les fichiers de vos disquettes. Rien n'est inclus dans ce dépôt.
